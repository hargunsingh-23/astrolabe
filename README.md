# Astrolabe of the Vishanti 🧭
**Offline Android sensor monitor and tool suite built with Flutter[cite: 13].**

## Features
- **Sensor Enumeration**: Queries Android's SensorManager for live hardware data (accelerometer, gyroscope, etc.)[cite: 13].
- **Planar Calibration**: Real-time smoothed bubble level, protractor, and compass[cite: 13].
- **Session Telemetry**: Records sensor readings to CSV files with export and sharing capabilities[cite: 13].
- **Graceful Degradation**: Built-in simulation fallbacks for emulators[cite: 13].
